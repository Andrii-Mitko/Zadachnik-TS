# Zadachnik-TS

Навчальний репозиторій для вивчення та практики **TypeScript**. Містить практичні завдання, які допомагають закріплювати знання мови та розвивати навички розв'язання програмних задач.

## 🔗 Посилання

- **Live Demo:** https://andrii-mitko.github.io/Zadachnik-TS/
- **GitHub Repository:** https://github.com/Andrii-Mitko/Zadachnik-TS

## 🛠️ Технології

- TypeScript
- HTML5
- npm
- TypeScript Compiler (`tsc`)

## 🚀 Запуск проєкту

1. Переконайтеся, що встановлено [Node.js](https://nodejs.org/).
2. Клонуйте репозиторій:

   ```bash
   git clone https://github.com/Andrii-Mitko/Zadachnik-TS.git
   ```

3. Перейдіть до папки проєкту:

   ```bash
   cd Zadachnik-TS
   ```

4. Встановіть залежності:

   ```bash
   npm install
   ```

5. Перегляньте доступні команди в `package.json` і запустіть відповідний скрипт.

## 🎯 Призначення

Репозиторій використовується для навчання, практики та закріплення знань TypeScript. Це навчальна база для самостійного опрацювання коду й розв'язання задач.
